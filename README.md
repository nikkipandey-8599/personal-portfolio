# Nikki Pandey — AI Developer | Personal Portfolio

Welcome to my personal portfolio! This website showcases my skills, projects, and experience in AI development and related fields. The portfolio is built using modern HTML and CSS, focused on clean design and accessibility.

- **Modern, Responsive Design**: Looks stunning on all devices

## 🚀 Getting Started

### Prerequisites

- A local web server for preview (optional, e.g., VSCode Live Server)

### Viewing Locally

1. Clone the repository:
    ```bash
    git clone https://github.com/nikkipandey-8599/personal-portfolio.git
    cd personal-portfolio
    ```

2. Open `nikki.html` directly in your browser, **or** use a live server for best results.

### Folder Structure

```
personal-portfolio/
├── nikki.html
└── README.md
```

## 🖌️ Customization

- **Update Content:**  
  Edit `nikki.html` to change profile details, projects, skills, etc.
- **Style Tweaks:**  
  All theme variables and styles are defined in the `<style>` section at the top of `nikki.html`. Adjust colors, fonts, or layouts as desired.
